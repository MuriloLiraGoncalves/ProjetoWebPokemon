🎮 Pokémon Quiz - Quem és tu no mundo Pokémon?

🌟 Sobre o Projeto

Este é um Quiz Interativo desenvolvido para a disciplina de Programação para Web. O objetivo é proporcionar uma experiência divertida onde o utilizador descobre qual Pokémon inicial melhor combina com o seu jeito de ser através de uma análise de personalidade.

"Vais escolher o Bulbasaur, o Charmander ou o Squirtle? A tua personalidade dará a resposta!"

🚀 Tecnologias e Funcionalidades

💻 Core Tech

HTML5: Estrutura semântica das telas de navegação.

CSS3 (Pixel Art Design):

Uso da fonte Google Font 'Press Start 2P'.

Fundo dinâmico com padrão de sprites e renderização nítida (image-rendering: pixelated).

Animações de transição para uma experiência mais fluida.

JavaScript (ES6+): Lógica robusta e moderna aplicada ao motor do quiz através de Orientação a Objetos.

🧠 Diferenciais Técnicos (Requisitos Académicos)

✅ Orientação a Objetos (POO): Gestão centralizada através da classe PokemonQuiz.

✅ Manipulação do DOM: Interatividade total sem necessidade de recarregar a página.

✅ Lógica de Pontuação: Sistema de pesos acumulativos para definição do resultado.

✅ Listas e Objetos: Organização eficiente dos dados de perguntas e personagens.

🎨 Aspeto Visual

O design foi cuidadosamente planeado para remeter aos jogos clássicos de GameBoy:

Menu de Batalha: Botões interativos que exibem o cursor ▶ ao passar o rato.

Identidade Visual: Cores vibrantes baseadas na marca oficial Pokémon.

Sprites: Imagens dinâmicas obtidas diretamente da PokéAPI.

📖 Como Jogar na tua Máquina
